## 📋 About
A personal portfolio built using modern web technologies. Features a sleek dark theme with glowing red accents, smooth animations, and scroll-triggered reveals. Highlights my technical skills, featured projects, academic background, and contact information in a clean, responsive single-page layout.

## 🎨 Design
- **Color Scheme** — Deep black backgrounds with glowing primary red accents
- **Typography** — F1-inspired bold fonts (headings) + Modern Sans (body)
- **Animations** — Loading screen, floating elements, shimmer gradients, and scroll-triggered reveals built with Framer Motion
- **Custom Elements** — Modern tech stack representation and progressive scroll indicators
